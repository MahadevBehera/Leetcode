# [Sparse Number](https://www.geeksforgeeks.org/problems/number-is-sparse-or-not-1587115620/1)
## Easy
Given a number n. You have to check whether it is sparse or not. &nbsp;A number is said to be a sparse number if no two or more consecutive bits are set&nbsp;in the binary representation.Examples :Input: n = 2
Output: true
Explanation: Binary Representation of 2 is 10, which is not having consecutive set bits. So, it is sparse number.Input: n = 3
Output: false
Explanation: Binary Representation of 3 is 11, which is having consecutive set bits in it. So, it is not a sparse number.
