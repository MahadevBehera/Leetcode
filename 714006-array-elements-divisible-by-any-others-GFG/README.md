# [Array Elements Divisible by Any Others](https://www.geeksforgeeks.org/problems/count-special-numbers--170647/1)
## Medium
Given an array of positive integers arr[]. You need to find the count of the special numbers in arr[].&nbsp; A number is said to be a special number if it is divisible by atleast one other element of arr[].&nbsp;
Examples :
Input: arr[] = [1, 2, 3]
Output: 2
Explanation: 2 and 3 are divible by 1.
Input: arr[] = [2, 3, 4, 6, 8, 9]
Output: 4Explanation: 4, 6, 8 are divible by 2 and 9 is divisible by 3.
Constraints:1 ≤ arr.size() ≤ 105&nbsp;1 ≤ arr[i]&nbsp;≤ 106&nbsp;
